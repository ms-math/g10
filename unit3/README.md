# Unit 3 Review — Grade 10 Math

Two review activities for Unit 3 (quadratic functions):

- **`practice/`** — Quadratics Practice: self-checking questions on types of functions, key features, the a-value and step pattern, vertex form, factored form and word problems, at three levels, with hints and worked steps. Students can plot points and type equations.
- **`launchlab/`** — Launch Lab: a retro puzzle-workshop game set in Ottawa's Ingenium museum, where students type quadratic equations to aim launchers.
- **`index.html`** — a landing page that links to both.

Everything runs in the browser. There is no server, no login, no tracking, and nothing is sent anywhere.

## Put it online with GitHub Pages

1. Create a new **public** repository on GitHub (for example `unit3-review`).
2. Upload everything in this folder to the repository, keeping the folder structure (`index.html`, `practice/`, `launchlab/`, `fonts/`).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the **main** branch and the **/ (root)** folder, then **Save**.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/unit3-review/`.
   - Practice page: `…/unit3-review/practice/`
   - Game: `…/unit3-review/launchlab/`

## Privacy

- **No student data.** The pages don't collect, store or send names, answers or scores. Names typed into the game stay on screen and disappear when the tab closes.
- **No outside requests.** Fonts are included in `fonts/`, so the pages don't contact Google Fonts or any other service.
- **One local setting.** The practice page remembers the last skill and level picked, in that browser only (`localStorage`). It never leaves the device.
- **Search engines.** Each page asks search engines not to index it (`noindex`). The link still works for anyone who has it.

Things about *you* that GitHub shows:

- Your **GitHub username** is in the site address and on the repository.
- Your **commit email** can appear in the repository history. To hide it, turn on **Settings → Emails → Keep my email addresses private** before uploading.
