## Privacy

- No student data is collected or sent anywhere. The pages load nothing from other websites: fonts are in `fonts/`.
- Names typed into the game stay on screen only. The mission code is made on the student's screen and checked on the title screen's teacher checker; nothing is saved.
- The practice page remembers the last skill and level in the browser's local storage.
