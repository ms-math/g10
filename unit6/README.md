## Adding this unit
Drag the whole `unit6` folder into the `g10` repository, then add a row for Unit 6 to the root README.

## Hand-in link
Paste the pre-filled Google Form link from the Apps Script log into `const HANDIN_URL = "";` near the top of the script in `hedges/index.html`. While it is empty, the game shows the code for students to hand in another way.

## Privacy
The pages hold no student data. Names typed into the game stay on screen and are only used to make the maze code. Codes are made and checked on screen, and are sent only if a student presses Submit on the teacher's Google Form. Nothing loads from outside hosts.
